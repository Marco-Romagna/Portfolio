# Official Artwork Sprites

These sprites are the official Pokémon artwork images provided through [PokeAPI/sprites](https://github.com/PokeAPI/sprites).

- **Source repository:** [https://github.com/PokeAPI/sprites](https://github.com/PokeAPI/sprites)  
- **Path in source:** `sprites/pokemon/other/official-artwork/`  
- **Format:** PNG images, transparent background  
- **Coverage:** National Dex #001 (Bulbasaur) through #1010 (Iron Leaves), including Generation 1–9 and DLC Pokémon where available.

## Notes

- Artwork is owned by **Nintendo / Game Freak / Creatures Inc.** This repository only mirrors files for fan, non-commercial use.  
- If you want the full dataset, clone the [PokeAPI/sprites](https://github.com/PokeAPI/sprites) repo and look in the `official-artwork` folder.
