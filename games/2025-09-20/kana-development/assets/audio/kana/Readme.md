# Kana Audio Library

This directory contains **Japanese kana audio files**, organized by **speaker gender**  
and further grouped by **syllable type** (basic vowels, consonant rows, dakuten, etc.).

All recordings are sourced from **Lingua Libre** (CC-BY-SA), using one consistent male and one consistent female speaker.

---

## 📂 Structure

/assets/audio/kana/
│
├── male/ → Male voice kana
│ ├── basic/ (a, i, u, e, o)
│ ├── k/ (ka, ki, ku, ke, ko)
│ ├── s/ (sa, shi, su, se, so)
│ ├── t/ (ta, chi, tsu, te, to)
│ ├── n/ (na, ni, nu, ne, no)
│ ├── h/ (ha, hi, fu, he, ho)
│ ├── m/ (ma, mi, mu, me, mo)
│ ├── y/ (ya, yu, yo)
│ ├── r/ (ra, ri, ru, re, ro)
│ ├── w/ (wa, wo, n)
│ ├── dakuten/ (ga, gi, gu, ge, go … za, ji, zu, ze, zo … da, de, do)
│ ├── handakuten/ (pa, pi, pu, pe, po)
│ └── combos/ (kya, kyu, kyo … sha, shu, sho … cha, chu, cho … nya, hya, mya, rya, etc.)
│
├── female/ → Female voice kana
│ └── (mirrors the same structure as above)
│
└── README.md → This file


---

## 🎧 File Naming
- Files use **romaji names** for easy reference:
  - `a.mp3`
  - `ka.mp3`
  - `shi.mp3`
  - `kya.mp3`

---

## 🔖 Notes
- All files are normalized to **consistent volume**.
- Each gender folder (`male/`, `female/`) includes its own `README.md` describing the subgroups.
- Great for:
  - Kana learning apps
  - Flashcards
  - Audio playback in games / web projects
