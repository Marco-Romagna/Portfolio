# Kana Audio Library

This directory contains **Japanese kana audio files**, organized by **speaker gender**  
and further grouped by **syllable type** (basic vowels, consonant rows, dakuten, etc.).

All recordings are sourced from **Lingua Libre** (CC-BY-SA), using one consistent male and one consistent female speaker.

---

## 🎧 File Naming
- Files use **romaji names** for easy reference:
  - `a.mp3`
  - `ka.mp3`
  - `shi.mp3`
  - `kya.mp3`

---

## 🔖 Notes
- All files are normalized to **consistent volume**.
- Each gender folder (`male/`, `female/`) includes its own `README.md` describing the subgroups.
- Great for:
  - Kana learning apps
  - Flashcards
  - Audio playback in games / web projects
