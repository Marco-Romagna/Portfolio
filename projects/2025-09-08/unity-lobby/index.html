Unity Lobby (Matchmaking Prototype)

Added: 2025-09-08

Overview

Lightweight lobby-based matchmaking flow for a Unity project: create/join realm, password-gated sessions, guest list, and clean close rules. Built with future 1v1→3v3 scaling in mind.

  • Password-protected “host realm” creation
  • Guest middle page with available realms & join flow
  • Session persistence: save/load realm name & password
  • Live roster count + usernames for host
